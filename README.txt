BrandCraft by Fazal - Portfolio website
=======================================

index.html is the whole site in one file (the poster image is embedded).
Double-click it to open in any browser.

Put it online free with GitHub Pages:
1. Open your GitHub repository for jonrambok.github.io/fazal
2. Upload index.html to the root of the repo (replace the old one)
3. Commit. The site updates in about a minute.

Things to edit (open index.html in any text editor):
- Phone/WhatsApp: search for 923012292471
- Instagram/Facebook: search for brandcraft.design
- Packages: search for "pkg" and change the list items
- Real projects: replace the "Concept" tiles in the section id="work"
